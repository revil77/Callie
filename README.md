# Callie Bot 🤖💬

Ecossistema avançado de bot para WhatsApp desenvolvido com arquitetura modular, focado em alta performance, automação e inteligência artificial.

## 🚀 Tecnologias e Recursos
- **Node.js**: Ambiente de execução backend de alta performance.
- **Baileys**: Biblioteca robusta para conexão não-oficial com o WhatsApp Web.
- **CallieTts**: Sistema inteligente integrado para transformação de texto em áudio de alta qualidade.
